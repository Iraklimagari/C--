# Bootstrap Icons — local subset

Official Bootstrap Icons v1.11.3, copyright The Bootstrap Authors, MIT licence (full text in LICENSE).
Only linkedin.svg, instagram.svg, tiktok.svg, youtube.svg (brand marks in the footer) and envelope.svg,
telephone.svg (footer contact lines) are included. No icon runtime or package is installed. The SVG paths
are unchanged; components.py inlines them, adds aria-hidden/focusable and lets them inherit the text colour.
Brand names and logos belong to their owners and are used only to link to the NAHLIO profiles.
