# Feather icons — local subset

Official Feather v4.29.2, copyright Cole Bemis, MIT licence (full text in LICENSE).
Only map-pin.svg, image.svg, list.svg, phone.svg and thumbs-up.svg are included.
No icon runtime or package is installed. The SVG paths are unchanged; rendering adds
accessibility attributes and inherits the site's colour.
